Moontide Macro plugins
======================

Put a plugin here: a .ahk file, or a folder with a plugin.ahk inside.
Then open the dashboard: Quests & events > Plugins, press Rescan, switch it
on and press "Restart to load".

- A new plugin is off until you switch it on.
- Before it loads, the macro checks it in a separate process. A broken file
  only shows an error on the Plugins tab; it never stops the macro.
- Updates never change or delete anything in this folder.
- Only add plugins from people you trust: a plugin runs inside the macro and
  can do anything the macro can.

example_plugin.ahk.txt is a small example. Rename it to example_plugin.ahk
to try it. How to write your own: the README, section "Plugins".
